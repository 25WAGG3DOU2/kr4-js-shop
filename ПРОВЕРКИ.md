# Проверка проекта

Дата: 16 ноября 2026 года.

## Выполнено автоматически

- `node tools/check.cjs` — успешно: 15 проверок массива, поиска, фильтрации, сортировки, поиска по id, расчётов и правил формы; дополнительно проверены локальные ссылки и ресурсы всех пяти страниц.
- `node --check` для четырёх файлов `js/*.js` — синтаксических ошибок нет.
- `tools/browser-check.cjs`, Playwright и установленный Microsoft Edge в фоновом режиме — успешно.
- Все пять страниц открыты в браузере; необработанных ошибок JavaScript не зафиксировано.
- В каталоге изначально 8 карточек; поиск ` RAZER ` даёт 2; несовместимая категория показывает пустую выдачу; сброс восстанавливает каталог; фильтр наличия оставляет 6.
- Проверены сортировки по цене в обе стороны и отключённая кнопка отсутствующего товара. Сортировка по названию реализована через `localeCompare` и доступна для ручного показа.
- Текст, похожий на HTML, не создаёт HTML-элементов через поиск.
- Кнопка товара №3 открывает форму с выбранным товаром №3.
- Пустая форма показывает 4 ошибки; корректно заполненная проходит проверку и сообщает, что данные не отправлены.
- Тема сохраняется после перезагрузки при открытии через локальный HTTP-сервер.
- Все 5 страниц проверены на ширинах 375, 768 и 1440 пикселей; горизонтальное переполнение страницы не обнаружено.
- Сохранён и просмотрен снимок `Проверка-каталог.png`: каталог читается, карточки и элементы управления не перекрываются.

При проверке внешние шрифты Google отключены: использовались резервные системные шрифты. Магазин не зависит от их загрузки. Первый запуск Edge внутри ограниченной среды не удался; повторная проверка с разрешённым запуском браузера прошла полностью.

## Готовность и границы проверки

Проект технически готов для локального показа обязательной части КР №4 и одной дополнительной функции (тема с сохранением). Серверная отправка заявки не входит в реализацию. Старый отчёт Lighthouse КР №3 не используется как доказательство качества КР №4; новый Lighthouse-аудит не проводился.

Для сдачи в СДО ещё нужна ссылка на отдельный удалённый репозиторий. Он не создавался и проект не публиковался. Перед защитой нужно разобрать код по памятке `ЗАЩИТА.md`; способность автора объяснить решение автоматически не проверяется. Максимальный балл не гарантируется.
