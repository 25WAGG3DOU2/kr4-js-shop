## Практическое занятие №16: данные и расчёты

`products` содержит восемь товаров игровой периферии пяти категорий. Все объекты имеют одинаковые поля: `id` (уникальное число), `title`, `category`, `price` (число), `isAvailable` (логическое значение), `description`. Цены учебные, их актуальность для покупки не заявляется.

В `catalog.js` реализованы:

- `getProductTitles` — получение названий через `map`;
- `getAvailableProducts`, `countAvailableProducts` — фильтрация и подсчёт наличия;
- `searchProducts` — поиск через `trim`, `toLowerCase`, `includes` и `filter`;
- `filterProductsByCategory` — фильтрация по категории;
- `sortProductsByPrice` — сортировка копии массива по возрастанию или убыванию;
- `findProductById` — поиск через `find`;
- `calculateTotalPrice` — сумма выбранного массива через `reduce`;
- `calculateAveragePrice` — средняя цена, для пустого массива возвращается 0;
- `getPreparedProducts` — совместное применение поиска, фильтров и сортировки;
- `formatPrice` — форматирование рублей.

На главной через `textContent` показаны количество товаров (8), наличие (6), средняя цена (20 491 ₽) и сумма всех цен (163 930 ₽). Функции можно вызвать в консоли браузера, например:

```js
console.table(products);
getProductTitles(products);
searchProducts(products, '  RAZER  ');
filterProductsByCategory(products, 'keyboard');
getAvailableProducts(products);
sortProductsByPrice(products, 'desc');
findProductById(products, 3);
calculateTotalPrice(products.filter(p => [3, 8].includes(p.id))); // 15480
calculateAveragePrice([]); // 0
```

## Практическое занятие №17: каталог и форма

Карточки каталога создаются через `createElement`, классы задаются через `classList`, текст — через `textContent`, элементы соединяются через `append`. В HTML каталога нет вручную написанных карточек.

Состояние `state` хранит запрос, категорию, сортировку и признак «Только в наличии». События `input` и `change` обновляют состояние и запускают повторный вывод. Поиск не зависит от регистра и краевых пробелов. Все условия работают одновременно. Сортировка доступна по цене в обе стороны и по названию. Исходный массив не изменяется. Выводятся число результатов и сообщение при пустой выдаче. Кнопка сброса возвращает начальное состояние.

Кнопки содержат `dataset.productId`. Один обработчик `click` на контейнере обрабатывает нажатия на динамические карточки — это делегирование событий. Доступный товар передаётся в форму через `order.html?product=3`. Отсутствующие товары нельзя заказать. Произвольный параметр URL не вставляется в страницу: выбирается только существующий доступный товар из массива.

Форма проверяет имя (минимум 2 символа после удаления краевых пробелов), e-mail, российский телефон (11 цифр с первой 7 или 8) и согласие. Ошибки расположены возле полей, связаны с ними через `aria-describedby`; неверные поля отмечаются `aria-invalid`. При вводе ошибки обновляются. При отправке вызывается `preventDefault`, после успешной проверки появляется сообщение «Данные не отправлены». Серверная отправка не реализуется в этой учебной работе. Контактные данные не сохраняются и не выводятся в консоль.

## Безопасность и события

Используются `querySelector`, `createElement`, `textContent`, `classList`, `append`, `addEventListener`. Пользовательский текст не обрабатывается как HTML. `innerHTML`, `alert` и inline-обработчиков событий нет. Инициализация каталога и формы проверяет существование нужных элементов, поэтому общие скрипты можно подключить ко всем пяти страницам.

## Ровно одна дополнительная функция

**Светлая/тёмная тема с сохранением выбора в `localStorage`.** Возможность взята из КР №3 и доработана: состояние кнопки доступно через `aria-pressed`, сохранение защищено от ошибки при запрете хранилища, используется `classList`. Выбор сохраняется после перезагрузки при доступном хранилище. Другие дополнительные задания не выполнялись. Количество найденных товаров и пустая выдача относятся к обязательным требованиям занятия №17.

## Автоматическая проверка

При установленном Node.js: `node tools/check.cjs`. Браузерная проверка: `node tools/browser-check.cjs` при доступных Playwright и Microsoft Edge. Для нестандартного расположения библиотек задайте переменную `SHOP_NODE_MODULES`. Эти библиотеки нужны только для проверки, сам магазин работает без них.
